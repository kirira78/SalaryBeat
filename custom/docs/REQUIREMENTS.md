# SalaryBeat · 薪跳需求规格

已确认于 2026-11-07。基于 SalaryGlow（MIT），中国日历来自 holiday-cn（MIT）；独立实现 PayDance 风格的数字滚动，不复制 AGPL 代码或素材。

## 计薪
- 人民币月收入按所属月份配置，允许预录未来月份，到账日不参与计算。
- 统一秒薪 = 月收入 / 全月所有计薪时段总秒数；收入显示 2 位、秒薪 6 位，内部 decimal 运算，不按显示精度截断。
- 按自然日 00:00 分割，每周七天分别支持多个不重叠时段；间隔即午休/break，可至 24:00。
- 基础双休；单休每周六上班；大小周与单休互斥，以选定双休周的任意日期为基准、周一为周首，连续交替，不跨月重置。
- 优先级：手动日期覆盖 > 国家放假/调休 > 每周排班。放假不累计，补班累计；不得重复计入。
- 新增工作日无时段时使用周一时段，允许日期单独设置；额外休息日计零。
- 修改选中月份设置即整月重算，包含已经过时间；成为后续未配置月份默认值，历史月份不变。
- 月份切换未预录时沿用此前最近月份收入/常规排班，不复制日期覆盖；主界面持续提示确认收入，保存后消失。
- 关机/休眠/退出不影响累计，按当前时刻重算；非工作时段保持显示、停止增长、标明状态。

## 界面与 Windows
- Windows 10/11，开机自启；本地保存，不上传工资，不依赖服务器。
- 默认今日为主、本月为辅，点击切换主次，另显本月秒薪；变化的数位里程表式滚动。
- 完整看板/透明迷你窗互斥，通过托盘切换；均默认置顶于普通窗口。
- 迷你窗默认鼠标穿透，通过托盘解锁拖动/切换后可重新锁定。
- 默认跟随系统深浅色，可手动选择；设置入口在完整看板右下角。

## 实施默认值与异常处理
- 使用电脑本地自然日期/时间；初始周一至周五 09:00–12:00、13:00–17:00，周末空时段。
- 大小周基准明确标注“双休周”；上游 SalaryGlow 使用相同语义。
- 未设置首次收入不展示虚构工资；没有工作秒数时显示零及修正提示，不能除零。
- 日历未覆盖某年时显示持续警告，不将普通周历冒充官方安排；支持导入 holiday-cn 年度 JSON。
- 同一日期的自定义时段必须与工作日覆盖一起保存；时段格式 HH:mm–HH:mm，支持多个分段与末尾 24:00，不允许跨午夜/重叠。
- 设置写入采用临时文件与上一份备份；文件损坏不静默覆盖，用户可从备份恢复。
- 后续月份已显式保存过的设置不被覆盖；未确认继承月份随最近已配置月份推导。

## 验收
- 法定假、补班、单休/大小周、手动覆盖与不等长班次的总秒数正确。
- 午休暂停、边界时刻、月末封顶、历史/未来查询、月切换提醒与重新分摊有自动化验证。
- 本地持久化往返及备份恢复有验证。
- Windows 构建成功；托盘、置顶、穿透、主题、动画与启动项需 Windows 实机验证，未实测须明确列出。
