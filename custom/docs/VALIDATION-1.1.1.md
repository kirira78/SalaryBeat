# SalaryBeat 1.1.1 显示回归记录

日期：2026-11-07。开发机 macOS ARM64；目标 Windows 10/11 x64。

## 修复内容

1. 金额滚动不再使用受 Grid 高度约束的两行 StackPanel。改用固定高度、绝对坐标的 Canvas 轨道，按实际字体测量字宽和行高。动画结束会移除旧轨道，还原一个位于原点的完整目标字符；小数点、逗号保持静态。
2. 新增统一 MoneyDisplay：显式 decimal 四舍五入至两位（中点远离零），主金额、辅助金额和迷你金额使用同一口径，不修改计薪内部精度。
3. 月份输入字号 12、收入字号 16；分别设置 34/42 像素高度和较小内边距。输入模板去掉内容宿主上重复的边距/额外内边距，保留 TextBox 自身 Padding，不用隐藏文字来掩盖问题。
