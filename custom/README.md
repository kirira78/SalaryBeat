# SalaryBeat · 薪跳 1.1.1

Windows 10/11 x64 桌面收入看板，基于 SalaryGlow（MIT）二次开发，数据与收入均保存在本机。

## 启动

先从托盘退出旧测试版，再运行 `SalaryBeat.exe`。自包含版本不需要安装 .NET。

**2026、2027 年 holiday-cn 日历已嵌入 EXE，无需用户下载，也不依赖旁边的 data 文件夹。** 包内同时保留年度 JSON，便于核对来源。另附 2025 年数据以支持历史月份。

## 新界面

- 主窗口 **640×400，横向 16:10**；首次使用或从旧版升级时自动停靠工作区右下角，避开任务栏。拖动后记住位置。
- 参考指定 Figma 预览的薄荷绿／深绿、橙色与淡紫卡片、大圆角，独立实现界面，没有复制其插画或素材。
- 默认今日收入为主、本月累计为辅，点击大金额或辅助金额切换；金额 2 位、秒薪 6 位，变化数位滚动。
- **设置是同一窗口的背面**：右下角设置按钮原地翻面，窗口大小／位置不变；保存或 ↩ 返回看板。四个设置分区局部滚动，未保存修改在返回后丢弃。
- 跟随 Windows 明暗主题，也可手动选择。关闭系统动画时，数字与翻面动画均改为直接更新。
- 透明迷你窗使用**白色加粗黑体字、深色轮廓阴影与薄荷绿环绕光晕**；默认鼠标穿透，通过托盘解锁后拖动、双击切换金额。完整窗与迷你窗互斥。
- × / — 收起到托盘，真正退出用托盘菜单。托盘图标可能位于“隐藏的图标”内。

## 计薪与设置

- 按收入所属月份配置，不按到账日重置；允许提前录入未来月份。
- 月收入 ÷ 全月所有计薪时段总秒数，得到统一秒薪。设置修改后整月重算，历史月份与已预录月份保持各自设置。
- 周一至周日可分别填写多段时段：`09:00-12:00;13:00-17:00`，间隔即午休。可用 `24:00` 作为终点；跨午夜必须拆到两天。
- 默认双休。单休固定周六上班；大小周以一个确定为双休周的日期为基准，两开关互斥。
- 手动日期覆盖 > 国家放假／调休补班 > 每周单双休；补班没有该星期时段时采用周一时段。
- 新月份未录收入时继承此前最近月份，不复制具体日期覆盖，持续提醒直到保存确认。关机、休眠或退出后重开会自动补算。
- 缺少某年日历时，主界面与设置都提供跳转到 **对应年度 JSON 页面** 的超链接；可在日历分区导入。2026–2027 年正常使用无需此步骤。
- 已保存月份冻结日历结果；导入更新后重新保存该月可采用新数据。

## 升级与数据

新目录 `%LOCALAPPDATA%\SalaryBeat\`，设置文件 `settings.json`，上一版 `settings.json.bak`。

首次升级会从 `%LOCALAPPDATA%\SalaryGlowLeo\` 导入设置和自定义日历，**不删除原文件、不覆盖已经存在的新版本设置**。旧版运行中会提示先退出。

自启仅管理当前用户 Run 下的 `SalaryBeat` 项，识别到本应用的旧 `SalaryGlowLeo` 启动项时迁移。移动 EXE 后重开会更新路径。

收入是按工作进度折算的估算值，不是银行到账；按电脑本地自然日与时钟计算。

## 构建

需要免费 .NET 10 SDK，源码位于本仓库 `custom/`。

```powershell
cd custom
dotnet run --project Tests/SalaryBeat.Tests.csproj -c Release
powershell -ExecutionPolicy Bypass -File build.ps1
```

输出 `dist/1.1.1/win-x64/SalaryBeat.exe`。可选 `-Runtime win-arm64`，本轮仅交付 x64。

Windows 可选界面自检／实际渲染（示例数据，不读写正式工资、不改启动项）：

```powershell
.\SalaryBeat.exe --render-preview .\ui-preview
```

成功会生成看板明暗、设置正反面与透明迷你窗 PNG。**当前开发机是 macOS，此 Windows 原生渲染自检尚未执行。**

## 1.1.1 显示修复

- 滚动数位改为固定坐标的独立画布，不再让双行内容参与自动居中；动画完成后替换为完整的静态数字。
- 所有收入显示显式四舍五入至两位（中点远离零），内部计薪精度不变；小数点和千位符不滚动。
- 月份输入字号降至 12、收入字号降至 16，调整高度和内边距，避免文字被挤压。
- Windows 原生界面回归入口：`SalaryBeat.exe --ui-regression ui-regression`。会比较动画结束后的实际像素与静态完整金额，并检查两个输入框首尾字符是否落在可视范围。结果及 PNG 保存在指定目录，不读写正式工资或启动项。
